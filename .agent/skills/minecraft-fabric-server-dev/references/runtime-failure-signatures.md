# 런타임 장애 시그니처 대응표

## 목차

1. 즉시 크래시 계열
2. 기동은 되지만 기능 깨짐 계열
3. 성능 저하 계열
4. 15분 트리아지 순서

## 1) 즉시 크래시 계열

### `NoSuchMethodError`

의미:
- 매핑/의존성 버전 조합 불일치 가능성이 가장 큼

즉시 점검:
1. `minecraft_version`, `yarn_mappings`, loader/api/polymer 버전
2. 최근 변경된 의존성
3. 빌드 캐시 정리 후 재빌드

### `InvalidInjectionException`

의미:
- Mixin 타겟 시그니처 또는 `@At` 지점 불일치

즉시 점검:
1. 대상 메서드 시그니처 재확인
2. `HEAD/TAIL`로 축소 재현
3. `require`/`priority` 검토

### `ClassNotFoundException` (Polymer 관련)

의미:
- 의존성 해석 실패 또는 API 경로 변경

즉시 점검:
1. `build.gradle` Polymer 의존 선언
2. repository 설정
3. 버전 호환성

## 2) 기동은 되지만 기능 깨짐 계열

### 명령은 동작하는데 시각 표현 불일치

원인 후보:
- core 상태 변경과 Polymer 갱신 타이밍 분리

대응:
- 상태 변경 진입점을 단일화하고 거기서 표현 갱신 호출

### 일부 기능만 동작 안 함

원인 후보:
- 특정 Mixin만 실패했는데 로그를 놓침

대응:
- mixin 로그를 기능 단위로 매핑해 확인

## 3) 성능 저하 계열

### 틱 지연 증가

원인 후보:
- 고빈도 경로에서 과도한 Mixin/Polymer 변환

대응:
1. 핫패스에서 로깅 제거 또는 샘플링
2. 대상 필터링(모든 플레이어/엔티티 순회 축소)
3. 캐시/재사용 적용

### 예외 로그가 반복

원인 후보:
- 에러 발생 후 재시도 루프

대응:
- 실패 시 백오프 또는 회로 차단
- 원인 파악 전까지 문제 경로 임시 비활성화

## 4) 15분 트리아지 순서

1. 최근 변경 파일 3개부터 확인
2. `gradle.properties` 버전 키 확인
3. `fabric.mod.json`, `*.mixins.json` JSON 파싱 확인
4. Mixin 실패 로그 키워드 검색
5. Polymer 경로 예외 검색
6. 핵심 기능 스모크 테스트 재실행
