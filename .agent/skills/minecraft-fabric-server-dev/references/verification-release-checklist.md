# 검증 및 릴리스 체크리스트 (Fabric 1.21.8 서버사이드)

## 목차

1. 사전 점검
2. 정적/구조 검증
3. 빌드/부팅 검증
4. 기능 회귀 검증
5. 성능/안정성 검증
6. 릴리스 게이트
7. 롤백 준비

## 1) 사전 점검

- 대상 브랜치/태그 확인
- 의존성 변경 범위 확인
- 장애 영향도(낮음/중간/높음) 분류

## 2) 정적/구조 검증

1. 스크립트 검증

```bash
./scripts/verify-mod-env.sh -ProjectDir <project_path>
```

2. 핵심 확인
- `fabric.mod.json` 파싱 가능
- `environment=server`
- `*.mixins.json` 파싱 가능
- placeholder 버전 미치환 없음

## 3) 빌드/부팅 검증

1. 빌드

```bash
./gradlew clean build --stacktrace
```

2. 개발 서버 부팅
- 엔트리포인트 초기화 확인
- Mixin apply 실패 0건
- 치명 예외 0건

## 4) 기능 회귀 검증

최소 시나리오:
1. 핵심 명령 실행
2. 핵심 이벤트(틱/상호작용) 실행
3. 권한 없는 사용자의 거부 흐름 확인
4. Polymer 표현 대상 기능 확인

## 5) 성능/안정성 검증

- 반복 틱 5~10분 관찰
- 예외 로그 반복 여부
- 다중 접속(가능한 범위 내) 동시 동작 확인

## 6) 릴리스 게이트

다음 조건을 모두 만족해야 릴리스:

- `FAIL` 0건
- Mixin 적용 실패 0건
- 치명 예외 0건
- 핵심 시나리오 전부 통과
- 롤백 절차 검토 완료

## 7) 롤백 준비

필수 보관:
- 직전 안정 버전 JAR
- 변경 이력 요약
- 롤백 절차 문서

롤백 절차 최소안:
1. 서비스 중지
2. JAR 교체
3. 서버 재시작
4. 핵심 기능 스모크 테스트
