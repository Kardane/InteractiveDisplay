# 검증/릴리스 체크리스트 (1.21.8)

## 목차

1. 사전 검증
2. 자동 검증
3. 인게임 검증
4. 서버 배포 검증
5. 릴리스/롤백 절차

## 1) 사전 검증

1. `pack.mcmeta` 확인
- `pack.pack_format == 64`
- JSON 파싱 가능

2. 경로/파일명 확인
- 소문자 경로
- 공백 없는 파일명
- 확장자 규칙 준수

3. 의존 경로 확인
- `blockstates` -> `models/block` -> `textures`
- `items` -> `models/item` -> `textures/item`
- `post_effect` -> `shaders/post`

## 2) 자동 검증

### 기본 실행

```bash
./scripts/validate_resourcepack_layout.sh --pack-dir <pack_path>
```

### 확인 항목

- 필수 파일(`pack.mcmeta`, `assets/`) 존재
- JSON 문법 파싱
- `pack_format` 64 일치
- 허용 확장자 검사
- `png.mcmeta` 짝 파일 검사
- `items`/`blockstates` 최소 키 검사

## 3) 인게임 검증

1. 리소스팩 로드 여부
- 옵션 화면에서 활성화 가능 여부

2. 시각 회귀 점검
- 인벤토리 아이콘
- 블록 배치/파괴 텍스처
- 엔티티 스킨/애니메이션
- GUI 패널/폰트

3. 고급 점검
- 파티클
- 후처리 효과
- 셰이더 렌더 이상(검정 화면, 노이즈)

## 4) 서버 배포 검증

1. 멀티 서버 배포 준비
- ZIP 파일 SHA 확인
- 리소스팩 URL/해시 갱신

2. 접속 검증
- 신규 접속 클라이언트에서 자동 다운로드/적용
- 기존 캐시 사용자에서 업데이트 반영

3. 모니터링
- 렌더링/충돌 이슈 보고 수집
- 저사양 클라이언트 프레임 드랍 확인

## 5) 릴리스/롤백 절차

1. 릴리스
- `vX.Y.Z` 식으로 버전 태깅
- 배포 ZIP + 변경 로그 함께 보관

2. 롤백
- 이전 안정 ZIP 즉시 복원
- 서버 리소스팩 URL/해시를 이전 값으로 되돌림

3. 사후 정리
- 장애 원인 파일 단위로 기록
- 동일 패턴 재발 방지 체크리스트 갱신
