# Minecraft Java Edition 1.21.11 실무 레퍼런스

## 목차

1. 운영 전제
2. 도메인 실행 카드
3. 1.21.8 대비 주의 지점
4. 운영 검증 루틴

## 1) 운영 전제

- `1.21.11` 기준 문서다.
- `1.21.8` 설계를 이식하는 경우 드리프트 검수부터 수행한다.
- 불확실한 문법/키는 단정하지 말고 검증 절차를 같이 제시한다.

## 2) 도메인 실행 카드

핵심 구조는 1.21.8과 동일하지만, 아래 원칙을 강화한다.

| 도메인 | 강화 포인트 | 실무 메모 |
|---|---|---|
| 명령어/선택자 | 체인을 더 짧게 분해 | 실패 지점 추적성 우선 |
| NBT/item component | 표현 혼용 금지 | 적용 대상과 타입 분리 |
| 데이터팩 | 로드 경로/진입점 재검증 | load/tick 함수 우선 확인 |
| 리소스팩 | 시각 품질 + 성능 동시 확인 | 고해상도 자산 과투입 주의 |
| 멀티 서버 | 권한/롤백/모니터링 강화 | 운영 변경은 단계 배포 |

## 3) 1.21.8 대비 주의 지점

점검 순서:

1. 명령어 체인
- `/execute` 대상/조건/실행 단위를 분리해 동일 결과인지 확인

2. 데이터 표현
- NBT 경로와 item component 적용 순서 확인

3. 데이터팩 진입점
- `load`, `tick` 호출 흐름 확인

4. 운영 기본값
- gamerule/권한/로그 정책 점검

5. 밸런스
- 루트 테이블/상태 효과/피해 분류 조정 영향 점검

드리프트 보고 템플릿:

```markdown
드리프트 후보: <도메인>
영향 범위: 낮음|중간|높음
재현 방법: ...
임시 완화: ...
근본 수정: ...
```

## 4) 운영 검증 루틴

### 최소 검증 세트

```mcfunction
/execute as @a run say version-check
/execute as @a[scores={quest=1..}] run say logic-check
/data get entity @p
```

### 배포 전 필수

1. 백업/복구 리허설
2. 관리자 권한 시나리오
3. 고부하 10분 테스트
4. 치명 로그 0건 확인

### 답변 품질 체크

- 기준 버전이 첫 줄에 있는가
- 도메인 경계가 분리됐는가
- 최소 실행 예시가 있는가
- 리스크와 완화책이 동시에 있는가
