# 멀티플레이어 운영/트러블슈팅 플레이북

## 목차

1. 장애 분류
2. 15분 트리아지
3. 즉시 완화책
4. 근본 조치

## 1) 장애 분류

| 증상 | 우선 원인 후보 |
|---|---|
| TPS 급락 | 반복 명령 과다, 엔티티 밀도, 구조물 farm |
| 기능 일부 미동작 | 데이터팩 진입점 누락, 권한 정책 충돌 |
| 플레이어만 문제 | 계정/권한/클라이언트 캐시 |
| 전체 서버 불안정 | 설정 변경 누적, 운영 절차 누락 |

## 2) 15분 트리아지

1. 최근 변경분 확인
2. 치명 로그 키워드 확인
3. 기능 범위(개인/전체) 분리
4. 임시 완화 적용
5. 롤백 여부 결정

## 3) 즉시 완화책

1. 고빈도 반복 명령 비활성화
2. 엔티티 밀집 구간 정리
3. 이벤트성 보상/드롭 임시 축소
4. 관리자 전용 복구 명령 실행

## 4) 근본 조치

1. 변경 단위를 축소해 재배포
2. 권한/역할 모델 재점검
3. 성능 모니터링 임계치 재설정
4. 롤백 리허설 주기화
