# 버전 차이 운영 가이드 (1.21.8 vs 1.21.11)

## 목차

1. 비교 원칙
2. 리스크 높은 영역
3. 마이그레이션 순서
4. 롤백 기준

## 1) 비교 원칙

- 목표는 "차이 나열"이 아니라 "장애 없는 이행"이다.
- 차이를 발견하면 즉시 영향도(낮음/중간/높음)로 분류한다.
- 변경은 한 번에 한 축씩 적용한다.

## 2) 리스크 높은 영역

| 영역 | 위험도 | 설명 |
|---|---|---|
| 명령어 체인 | 중간~높음 | 선택자/조건식/실행 순서 차이 누적 |
| NBT/item component | 높음 | 표현 혼용 시 런타임 오류 유발 |
| 데이터팩 진입점 | 높음 | load/tick 누락 시 기능 전반 실패 |
| 멀티 서버 운영 | 높음 | 권한/백업/성능 이슈가 동시 폭발 |
| 리소스팩 품질 | 중간 | 가독성/성능 회귀 가능 |

## 3) 마이그레이션 순서

1. 백업 고정
- 월드, 데이터팩, 설정, 플러그인/모드 목록 백업

2. 핵심 명령 검증
- 최소 명령 세트 실행

3. 데이터팩 검증
- `/reload` 로그
- load/tick 진입
- 핵심 함수 회귀

4. 운영 검증
- 권한 시나리오
- 고부하 5~10분 테스트

5. 배포
- 단계 적용 후 모니터링 강화

## 4) 롤백 기준

다음 중 하나라도 해당하면 롤백:

1. 치명 로그 반복
2. 핵심 기능 실패
3. TPS 급락 지속
4. 관리자 복구 명령 실패

롤백 절차 최소안:
1. 변경 중지
2. 직전 안정 백업 복원
3. 서버 재기동
4. 스모크 테스트
